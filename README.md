# Bloque Funcional: demo de flitzfa

Web de ejemplo para un gimnasio. **Bloque Funcional es un negocio ficticio**: el nombre, las disciplinas, la grilla y los horarios son de ejemplo, y no hay dirección ni teléfono.

Publicada en https://gimnasio.flitzfa.com.ar · Hecha por [flitzfa](https://flitzfa.com.ar).

## Qué muestra

- Disciplinas y grilla semanal de clases.
- Planes y pasos para arrancar.
- Botones de WhatsApp en modo demo: muestran el mensaje armado y permiten copiarlo, pero no abren `wa.me` ni lo envían a ningún número.

Es HTML, CSS y JS sin dependencias ni build: se abre `index.html` directo o se sirve la carpeta tal cual.
